# Kubernetes and Cloud-Native Lab

> Deploy, connect, scale, and troubleshoot containerized workloads with Kubernetes.

## Overview

Containers simplify application packaging, but managing multiple containers across multiple machines introduces new challenges.

Kubernetes provides orchestration capabilities for deploying and managing containerized workloads.

This project explores Kubernetes architecture and its practical application.

## Learning Objectives

- Understand container orchestration.
- Explore Kubernetes architecture.
- Understand control plane and worker nodes.
- Work with Pods and Deployments.
- Understand Services and networking.
- Configure ConfigMaps and Secrets.
- Explore persistent volumes and storage.
- Understand ingress.
- Perform scaling and rolling updates.
- Troubleshoot failed workloads.
- Package applications using Helm.

## Practical Labs

| Lab          | Description                        |
| ------------ | ---------------------------------- |
| Architecture | Explore cluster components         |
| Pods         | Deploy individual workloads        |
| Deployments  | Manage application replicas        |
| Services     | Expose and connect applications    |
| ConfigMaps   | Manage application configuration   |
| Secrets      | Understand sensitive configuration |
| Storage      | Configure persistent storage       |
| Ingress      | Explore external HTTP access       |
| Helm         | Package reusable deployments       |

## Main Project

Deploy a multi-component application containing:

- Frontend.
- Backend API.
- Database.

Configure networking, application settings, storage, and health checks.
